# BATAKU (prototipe)

Satu file statis (`index.html`), tanpa build dan tanpa dependensi.

## Deploy gratis ke Vercel
1. Buat repositori GitHub baru, unggah `index.html` (dan file ini).
2. Masuk ke vercel.com dengan akun GitHub, pilih Add New > Project, impor repositori itu.
3. Framework Preset: Other. Biarkan kolom build kosong, lalu Deploy.

Alternatif lewat terminal: `npx vercel` di folder ini, lalu `npx vercel --prod`.

Paket Hobby Vercel gratis, tetapi ditujukan untuk penggunaan pribadi non-komersial. Untuk prototipe lomba ini cukup.
